# 🔖 Bookmarks Plugin Guide

Quick guide for using VS Code Bookmarks extension with your TypeScript learning files.

## 📦 Installation

1. Open VS Code Extensions (`Cmd+Shift+X`)
2. Search for **"Bookmarks"** by Alessandro Fragnani
3. Click **Install**

## 🚀 Quick Setup (Mac)

### Bookmark All Chapter Sections:
1. **`Cmd+F`** → Search for: `// =====`
2. **`Option+Enter`** → Selects ALL chapter headers
3. **`Cmd+Option+K`** → Bookmarks them all instantly! 🎉

## ⌨️ Keyboard Shortcuts (Mac)

| Action | Shortcut |
|--------|----------|
| Toggle Bookmark | `Cmd+Option+K` |
| Previous Bookmark | `Cmd+Option+J` |
| Next Bookmark | `Cmd+Option+L` |
| List All Bookmarks | `Cmd+Option+A` |

## 🗂️ Bookmarks Panel

1. Open **Explorer** sidebar (`Cmd+Shift+E`)
2. Scroll down to **"BOOKMARKS"** section
3. Click any bookmark to jump to it instantly

## 💡 Pro Tips

- **Label bookmarks**: Right-click bookmark → "Add Label"
- **Jump quickly**: Use `Cmd+Option+J/L` to navigate
- **See all**: Use `Cmd+Option+A` to choose from list
- **Clean up**: `Cmd+Shift+P` → "Bookmarks: Clear All"

## 🎯 Workflow

1. Bookmark all sections once using the setup above
2. Use `Cmd+Option+J/L` to jump between topics while learning
3. Perfect for reviewing specific concepts quickly!
